# Carta de Resolução — Marinha Mercante

## Etapa 1 — Estrutura profissional

O projeto foi separado em camadas:

- `app/` → páginas e futuras APIs
- `components/` → interface reutilizável
- `types/` → contratos dos dados
- `lib/` → regras e integrações
- `lib/supabase/` → banco de dados (Etapa 2)

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.
